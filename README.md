# Sensor Fault Detection

A machine learning-based system designed to detect faults in sensor data. This project includes data ingestion, preprocessing, model training, evaluation, and deployment through a Flask web application.

## Features

- **Data Pipeline**: Automated ingestion and preprocessing of sensor data.
- **Model Training**: Machine learning model to identify sensor faults.
- **Evaluation**: Assessment of model performance using standard metrics.
- **Deployment**: Flask-based web application for real-time fault detection.
- **Dockerization**: Containerized application for scalable deployment.


## Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Rishabhporwal/Sensor-Fault-Detection.git
   cd Sensor-Fault-Detection

   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate

   pip install -r requirements.txt

   python app.py



```
